# 책 골라주는 도서관

대학도서관 이용자를 위한 반응형 도서 추천 웹앱입니다.

## 실행

`index.html`을 브라우저에서 열어 사용하세요. 상단의 관리자 링크로 `admin.html`에 이동합니다. 별도 빌드나 패키지 설치는 필요하지 않습니다. 외부 글꼴이 로드되지 않아도 기본 글꼴로 동작합니다.

안정적인 페이지 간 데이터 공유를 위해서는 이 폴더에서 `python -m http.server 8000`으로 실행하고 `http://localhost:8000`에 접속하세요. 파일로 직접 여는 경우 브라우저에 따라 저장 공간이 페이지별로 분리될 수 있습니다.

## 기능

- 관심 분야 복수 선택, 독서 목적, 쪽수에 따른 조건 일치 추천
- 관심 분야는 선택 항목 중 하나, 나머지 조건은 모두 일치하는 도서 표시
- 제목순·쪽수순 정렬, 도서 상세 정보 및 추천 이유
- 내 책장 담기와 해제
- 관리자 도서 검색·등록·수정·삭제
- 모바일 대응 및 키보드 조작 지원

## 데이터와 운영 범위

초기 도서 12권은 예시 큐레이션이며, 소개는 앱용 요약입니다. 표지는 CSS로 구성한 디자인이며 실제 표지가 아닙니다. 쪽수는 판본에 따라 달라질 수 있습니다. 실제 도서관 소장·대출 데이터에 연결되어 있지 않습니다.

수정 도서와 책장은 현재 브라우저의 localStorage에 저장됩니다. 브라우저 데이터를 지우면 초기 상태로 돌아갑니다. 데이터가 없을 때만 예시 도서를 사용하며 전체 도서를 삭제한 상태는 유지됩니다.

관리자 화면은 인증 없는 로컬 체험용입니다. 실제 공동 서비스 운영에는 서버 저장소, 관리자 인증 및 서버 권한 검증, 도서관 데이터 연동이 필요합니다.
